# 🌦️ El Niño & Telangana Statistical Analysis

An interactive data analysis project that explores the relationship between **El Niño events and climate patterns in Telangana**, with a focus on **rainfall and temperature trends**.

The project transforms climate data into interactive visualizations to make statistical patterns, variations, and trends easier to explore and understand.

## 🌍 Overview

El Niño is a major climate phenomenon that can influence weather conditions across different regions of the world.

Telangana experiences significant variations in rainfall and temperature, making it interesting to study how regional climate patterns behave during different El Niño periods.

This project provides an interactive platform to explore these patterns through **statistical analysis, data visualization, and geographical representation**.

## 🎯 Objectives

* Analyze rainfall patterns in Telangana.
* Study temperature variations and trends.
* Examine climate data across different periods.
* Compare climate patterns during El Niño and non-El Niño periods.
* Identify noticeable trends and variations in the data.
* Present statistical findings through interactive visualizations.
* Make climate data easier to understand through a web-based interface.

## ✨ Key Features

### 📊 Statistical Analysis

Explore climate datasets and identify important patterns, variations, and trends using statistical analysis.

### 🌧️ Rainfall Analysis

Visualize rainfall behavior across different periods and examine changes and variations in rainfall patterns.

### 🌡️ Temperature Analysis

Analyze temperature data to understand variations and long-term trends.

### 🌊 El Niño Analysis

Compare climate patterns associated with El Niño periods with other periods to explore possible relationships and variations.

### 🗺️ Telangana Climate Visualization

Use geographical and regional visualizations to present climate-related information for Telangana.

### 📈 Interactive Charts

Interactive charts make it easier to explore climate trends and compare different datasets.

### 🤖 AI Integration

The project incorporates **Google Gemini / Google AI Studio capabilities** to enhance the application's analytical experience.

### 💻 Interactive Web Application

The analysis is presented through a responsive web interface rather than a static statistical report.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm or Bun
* Git

### Clone the Repository

```bash
git clone https://github.com/vyshnavimanthu-max/El-Ni-o-Telangana-Statistical-Analysis.git
```

### Navigate to the Project

```bash
cd El-Ni-o-Telangana-Statistical-Analysis
```

### Install Dependencies

Using npm:

```bash
npm install
```

Or using Bun:

```bash
bun install
```

### Environment Variables

Create a `.env.local` file and add the required API configuration:

```env
GEMINI_API_KEY=your_api_key_here
```

> Never commit your actual API key to GitHub.

### Run the Development Server

```bash
npm run dev
```

The application will be available on your local development server.
